# Contact (chip) AID configuration: the applications this terminal supports on the contact interface.
# Format: one TAG=VALUE; per line (hex), one AID per record, records separated by a blank line.
# 9F06 carries a leading length byte (07 = 7-byte AID). A card AID that matches no record fails selection.
#
#   9F06      Application Identifier (AID) - terminal
#   9F1A      Terminal Country Code            5F2A  Transaction Currency Code
#   5F36      Transaction Currency Exponent    9F09  Application Version Number (terminal)
#   9F918709  Terminal Action Code - Default   9F91870A  TAC - Denial   9F91870B  TAC - Online
#   9F1B      Terminal Floor Limit (binary, minor units)
